# marketing-assets

Public images for NerdSnipe marketing: dev.to covers and other images that need a permanent public link.

- `devto/`: dev.to article covers (1000x420 ratio)
- `social/YYYY-MM/`: X and LinkedIn post images and recordings (charts from our own data, product screenshots, DesignFoundation recordings)

Uploaded by the NerdSnipe marketing routine (`marketing/bin/host_image.py`). Files are served from
`https://raw.githubusercontent.com/NerdSnipe-Inc/marketing-assets/main/<path>`.

Everything here is public. Only marketing images, never anything private.
